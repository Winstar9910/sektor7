# Sektor 7

Team-Deathmatch-Shooter im Browser. Hobby-Prototyp von Bildkunst by Dahir.

Eine einzige HTML-Datei, keine Build-Schritte: Three.js per CDN, alle Sounds werden zur Laufzeit mit der Web Audio API erzeugt, Texturen sind prozedural.

## Spielen

- Handy: Link in Chrome oeffnen, quer halten, "Vollbild" tippen. Linker Stick laeuft, rechter Stick zielt und feuert, Wischen dreht die Kamera.
- Desktop: WASD, Maus, Linksklick feuert, 1/2/3 Waffen, R Nachladen, H Helikopter, N Nuke.

Erstes Team mit 30 Abschuessen gewinnt. Killstreaks: Helikopter ab 3, Nuke ab 7 Abschuessen in Serie.

## Lokal starten

Datei direkt oeffnen oder mit einem beliebigen Webserver ausliefern, z. B. `npx serve .`
